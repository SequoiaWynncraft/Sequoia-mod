## Sequoia 1.16.0

Patch notes now open in game.
The update prompt shows a short summary of each release, and What's new shows the full notes.

### New

- **What's new.** The update prompt has a What's new button that opens the release's full notes.
  - Scroll with the mouse wheel, drag the scrollbar, or drag the text itself.
  - Esc or Back returns to the prompt.
- **A summary first.** A few lines about the release show under the prompt's title.
- After Sequoia updates itself, `/seq update` shows the notes of the version you are running.

### Changed

- The update prompt grows taller when the summary needs the room, and stays inside the window.
- With four buttons, the prompt's buttons share its width instead of running off its edges.
- The message after Sequoia updates itself says to use `/seq update` to see what's new.
